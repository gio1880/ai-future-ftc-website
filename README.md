# AI Future · FTC Team #31591

The team website for AI Future, FIRST Tech Challenge Team #31591 (BIOBUZZ 2026–27).
Plain HTML and CSS, published with GitHub Pages from the `main` branch.

| Page | What it's for |
|---|---|
| `index.html` | Home: this season so far, next event, links for judges |
| `robot.html` | Design + Control: the robot right now (CR1 v6), how we build in-house, how we control it |
| `season-story.html` | The 12 biggest decisions of the season |
| `versions.html` | Wood robot -> CR1 -> CR1 v6 -> v6 METAL, with each version's EN entries |
| `notebook.html` | Every EN entry (EN-01..EN-115) in one sentence, grouped by subsystem, anchors `#en-NN` |
| `october-stories.html` | The 5 October design stories (wood robot, EN-01..44) |
| `assets/site.css` | Shared look, also used for the FLL team site |

Photos go in `img/` as compressed `.webp` files (about 1400 px on the long side), with `loading="lazy"` and alt text.

| Folder | What's in it |
|---|---|
| `img/notebook/intake/`, `pollen/`, `nectar/`, `drive/`, `inhouse/` | Pictures for each notebook story (CAD, drawings, bench photos) |
| `img/robot/` | Robot page pictures |
| `img/build/` | Last season's team photos (not shown on any page: no guardian consent for faces yet) |

No student names or faces on public pages. Only parts, CAD, the robot and whiteboards.

Agents (Claude + Codex): read `AGENTS.md` and the end of `HANDOFF.md` first.
