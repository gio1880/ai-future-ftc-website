Engineering Notebook

Every time we fix or design something on the robot, we write it up as an entry (EN). We have written 121 entries from September 24 to November 23. Here is each one in a sentence, grouped by part of the robot.

New here? Start with the season story (the big decisions) or the robot versions (how the robot changed).

Drivetrain 13 Intake, lane + transfer 31 Shooter, turret + head 36 Flower wedge 9 Electronics + code 8 Frame + build process 24

What each entry covers

  1. Problem: what we saw on the robot or in CAD.
  2. Analysis: what we measured and why it happened, with real numbers.
  3. Options: the ideas we compared, with pros and cons.
  4. Decision: what we picked and why.
  5. Build: the parts and files we made.
  6. Test: how it worked, and what's next.

We say plainly how far each one got: Built + tested Built, testing Files ready (cut and print files made, not made yet) CAD only Plan / study Not chosen. The tag shows which robot version it belongs to: Wood robot CR1 CR1 v6 v6 METAL. There is no EN-87.
